# Brand Identity: WRSolid

## 1. Brand Foundations
* **Name:** WRSolid
* **Meaning:** *We Are Solid*.
* **Slogan:** *Built to Last.* (Spanish: *Hecho para durar.*)
* **Core idea:** **Solid foundations.** Software that keeps working, stays secure and is still easy to change years later. Visuals draw on stone and structure; copy stays plain.
* **Positioning:** Senior-led software consultancy. Every project is led by a senior software architect, from the first conversation to delivery.
* **Value Proposition:** Cloud architecture, custom software and DevOps for companies that need systems they can rely on: designed carefully, built by senior hands, and delivered faster with AI-assisted engineering.

### Audience
* **Small and mid-sized businesses** without their own technical team that need a system designed, built, migrated or fixed.
* **Companies with development teams** that need senior support in architecture, cloud, DevOps or performance.
* **Market:** Mexico, plus remote work across Latin America. Bilingual service in Spanish and English.

## 2. Services

Project delivery and consulting carry equal weight.

### Cloud Architecture & Migration
Design of cloud solutions on Azure and AWS, migration of existing systems, cost and reliability improvements.
* **Data & integration (supporting service):** ETL pipelines (Microsoft Fabric, Azure Data Factory), performance tuning of existing ETL processes, relational databases (Oracle, SQL Server, PostgreSQL) and NoSQL (Cosmos DB, DocumentDB, DynamoDB, Table Storage, OpenSearch).

### Custom Software Development
Web applications, backend services and APIs, full stack (.NET, Angular, TypeScript, Node.js). Includes integrations between systems and incremental modernization of legacy applications.

### DevOps & CI/CD
Build and release pipelines and automation with Azure DevOps, GitHub and TeamCity. Repeatable deployments, environment setup, and delivery practices that let small teams ship safely.

### Consulting
Architecture and code reviews, performance optimization, technical guidance for teams and decision-makers.

### Ways to engage
* **Fixed-scope projects:** a defined system, feature, migration or pipeline, quoted per project.
* **Assessment / review:** a short, fixed-price review (architecture, cloud setup and costs, CI/CD, data pipelines or performance) that ends with a written report and prioritized recommendations. The usual first step for a new client.

### AI in every service
AI is not sold as a separate service. AI agents are used across design, development, testing and documentation to deliver faster, and every change is reviewed by a senior engineer. Clients get the speed of AI-assisted work with the judgment of 20+ years of experience.

## 3. Identity Attributes
* **Senior, hands-on work:** Senior engineers stay involved from design to delivery; the work is never handed off to people who weren't part of the design.
* **Sound architecture:** Decisions are documented with their trade-offs. **SOLID principles**, clean boundaries and automated tests are the default.
* **Pragmatic technology:** Azure or AWS, SQL or NoSQL. The choice fits the problem and the team that will maintain it, not the trend.
* **Transparency:** Honest estimates, visible progress, and code and documentation that belong to the client.
* **Built to hand over:** Every project ends with a system the client's team, or the next developer, can understand and own.

## 5. Voice & Tone

Calm, precise, confident and understated. Write like a senior engineer explaining a decision to a business owner.

| Do | Don't |
| :--- | :--- |
| Name the problem and the outcome: "Deployments that take minutes, not days." | Abstract metaphors: "forging high-density systems". |
| Be specific: "Azure, AWS, .NET, SQL Server". | Superlatives: "elite", "world-class", "cutting-edge", "disruptive". |
| State only what can be backed up. | Uptime figures, partner badges, certifications or team sizes that don't exist. |
| Short sentences, plain words. | Buzzword chains: "AI-first neural cloud-native workflows". |
| Mention AI as part of how the work is done. | Make AI the headline. |

* **Words to avoid:** tungsten, forge, density, unbreakable, never fail, elite, disruptive, revolutionary, cutting-edge, neural.
* **Company voice:** always *WRSolid* / *we*. Team size is never stated; the About section presents the founder, not the headcount.
* **Spanish copy:** impersonal where possible ("Diseño y desarrollo de…", "Se entrega con…"). Where the reader must be addressed, use *usted*. In the About section, explain the name: *We Are Solid — Somos sólidos*.

### Brand Message
> "At WRSolid we build software the way solid structures are built: on clear foundations, with the right materials, and with the years ahead in mind. Every project is led by a senior architect, from the first conversation to the last line of code."

## 6. Visual Guide (Look & Feel)

### Logo
* **Isotype:** Hexagonal monogram with W and R side by side above a folded S. The hexagon represents structure and stability.
* **Wordmark:** "WRSOLID" in Montserrat, "WR" regular and "SOLID" bold, with a Signal Green dot above the "O".
* **Lockups:** horizontal (monogram + wordmark), stacked (optional "We Are Solid" underneath), monogram alone for favicons and avatars.
* **Master files are flat vectors.** The stone or engraved look is a presentation effect for hero images, signage and print, never part of the logo file.
* **Versions:** navy on light, chalk on dark, single-colour black and white.
* **Clear space:** at least the height of the "O". **Minimum size:** 24 px for the monogram, 100 px wide for the horizontal lockup.

### Color Palette
| Color | Hex | Usage |
| :--- | :--- | :--- |
| **Graphite** | `#1C1F22` | Main dark background |
| **Slate** | `#2C3136` | Cards and raised surfaces on dark |
| **Stone** | `#8C939B` | Secondary text, borders, dividers |
| **Chalk** | `#F3F3F1` | Text on dark, light-section background |
| **Deep Navy** | `#24375A` | Monogram and wordmark on light, headings on light sections |
| **Signal Green** | `#2BD46F` | Accent only: logo dot, primary call to action, focus states. Never for large areas or body text. |

### Typography
* **Headings and wordmark:** Montserrat (600–800).
* **Body and UI:** Inter (400–600).
* **Technical details** (optional, small sizes): JetBrains Mono.

### Imagery
* Real stone textures (slate, granite), darkened and low-contrast, behind the hero and the closing call to action.
* Generous whitespace, alternating dark (Graphite) and light (Chalk) sections.
* No neon glows, particle effects, fake code editors or generic stock photos.
